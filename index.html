Usage

<!-- Load the component -->
<script type="module" src="src/components/signal-graph.js"></script>

<!-- Use with data attribute (JSON) -->
<signal-graph data="[1,2,3,4,5]" renderer="canvas"></signal-graph>

<!-- Or set data programmatically -->
<script>
  const graph = document.querySelector('signal-graph');
  graph.data = [3.1, 4.2, 5.9, 2.6, 1.8];
  graph.renderer = 'svg';
</script>

<!-- Style via CSS custom properties -->
<style>
  signal-graph {
    --sg-line-color: #6fcf97;
    --sg-bg-color: #1a1a2e;
  }
</style>

Architecture

signal-graph (Custom Element)
├── Shadow DOM (closed mode — true encapsulation)
├── Signal system (reactive state management)
│   ├── signal() — tracked getter/setter
│   ├── computed() — lazy derived values
│   └── effect() — auto-reacting side effects
├── Renderer interface (swap without component changes)
│   ├── CanvasRenderer — high-frequency, sub-pixel
│   ├── SVGRenderer — vectors, accessibility
│   └── DOMRenderer — CSS transitions, text selection
└── CSS Custom Properties — theming API
